# CacheHit
O(1) memory retrieval for O(N) algorithm problems. A lightweight spaced-repetition tool built with React, Flask, and SQLite.

# ⚡ CacheHit

> **Pattern-based Spaced Repetition & Active Recall Engine.**  
> Stop endlessly grinding problems and forgetting them weeks later. **CacheHit** helps you capture the **Core Pattern**, **Complexity**, and **Key Intuition ("Aha!" Moment)** for competitive programming, language learning, system design, and more—scheduling timely re-implementations so solutions stick.

## Before you start
1. Create a virtual env
   python3 -m venv venv
2. Install the packages from the requirement file
    pip install -r requirements.txt

## 🚀 Quick Start (One Command)

CacheHit includes an automated launch script that starts both the Flask backend and the React/Vite frontend simultaneously, opening the app in your default browser.

```bash
# Make sure the script is executable (first time only)
chmod +x ./start.sh

# Run the complete stack
./start.sh
